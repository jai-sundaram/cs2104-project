Jai's Expense Tracker 

Project Overview:
An expense tracker that allows individuals to manage their expenses and regain control over their financial well-being. 
Functionalities: 
- Add Expenses
- View Expenses
- Delete Expenses
- Category Summary
- Monthly Summary 
- Focus on expenses for a particular month
- Budget Check
- Export Report

Navigate into the appropriate folder

Use the menu options to complete desired tasks
